Privacy policy

gmail-mcp, a personal helper tool · effective 20 November 2026 · home

Who this applies to

gmail-mcp has a single user: its owner. It connects only to the owner's own Google account and is not available to anyone else.

What data the tool accesses

When the owner runs a command, the tool accesses data in the owner's Google account through Google APIs: Gmail messages (to find, read, send and organise e-mail), Google Calendar events, Google Sheets, and the Google Drive files that the tool creates or opens.

How the data is used

Only to carry out the command the owner has just run, for example to send a message the owner wrote or to add an event the owner asked for. The data is processed on the owner's computer by the tool and by the software the owner chooses to run it with, including an AI assistant.

What the tool does not do

It does not sell Google user data, does not use it for advertising, does not use it to build profiles, and does not hand it to anyone else for their own purposes. It has no server of its own, no analytics and no tracking.

Storage and access tokens

The tool keeps its Google access tokens in a file on the owner's computer. The owner can revoke access at any time at myaccount.google.com/permissions; after that the tool can no longer reach the account.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised as an issue in the public repository that hosts this page.

По-русски

У инструмента один пользователь — владелец. Инструмент обращается только к его аккаунту Google и только когда владелец запускает команду: к письмам Gmail, событиям календаря, таблицам и к тем файлам Google Drive, которые сам создаёт или открывает. Данные обрабатываются на компьютере владельца — самим инструментом и программами, с которыми владелец его запускает, включая ИИ-ассистента. Данные не продаются, не используются для рекламы и не передаются другим лицам для их целей; своего сервера, аналитики и слежения у инструмента нет. Ключи доступа хранятся в файле на компьютере владельца; доступ можно отозвать на странице myaccount.google.com/permissions.
